# Ayush Gupta — Personal Portfolio

A responsive, single-page developer portfolio for **Ayush Gupta**, focused on backend engineering, AI-powered applications, data systems, and IoT.

## Preview

The site is implemented in `index.html` with responsive styling, a dark editorial design, project cards, experience, skills, contact links, and lightweight scroll reveals. It uses no build step or JavaScript framework.

## Run locally

Open `index.html` in a browser.

## Publish with GitHub Pages

1. Open this repository on GitHub.
2. Go to **Settings → Pages**.
3. Under **Build and deployment**, choose **Deploy from a branch**.
4. Select the `main` branch and `/ (root)`, then save.
5. Once the deployment completes, GitHub will show the published URL in the Pages section.
